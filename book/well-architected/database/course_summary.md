# Course Summary

This course covered the Well-Architected Framework and went over database solutions for it. You also learned about data characteristics and the several database services and offerings at Amazon Web Service (AWS). When you understand each data source type and how data is used by the application, you can determine the right AWS database service for each use case and some key solutions to building them.
